# Robot Manipulation — Use Cases

- Bin picking: select and grasp parts from clutter
- Kitting: pick-and-place specific parts into trays
- Assembly: align and insert components with pose tolerances
- Screwdriving prep: pose estimation for tool alignment
- Palletizing/depalletizing: stack/unstack with stable poses
- Conveyor pick: grab moving items with predictive pose
- Tool change handling: locate and grasp tools safely
- Fixture loading: place parts with orientation constraints
- Inspection handoff: present part for downstream QA
- Regrasp planning: handover to achieve target orientation
- Failure recovery: detect slip and replan quickly
- Collaborative assistance: guide human with pose overlays
