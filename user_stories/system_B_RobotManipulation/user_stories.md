# Robot Manipulation — User Stories

- As a robot operator, I want stable poses so that grasp retries decrease.
- As a planner engineer, I want grasp candidates ranked so that planning is faster.
- As a safety officer, I want safe stops on controller faults so that incidents are avoided.
- As a process engineer, I want re-observe triggers so that dynamic scenes are handled.
- As a QA engineer, I want overlays for grasps so that failure analysis is quicker.
- As a maintainer, I want config hot-reload so that changeovers are smooth.
- As IT, I want metrics and logs so that I can monitor success rate.
- As a line lead, I want pick-per-minute KPIs so that I can report efficiency.
- As an integrator, I want ROS2 topics documented so that integration is quick.
- As a manager, I want A/B deploys so that new models are de-risked.
- As a safety trainer, I want audit trails so that I can perform drills.
