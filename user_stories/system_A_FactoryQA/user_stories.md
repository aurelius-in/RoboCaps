# Factory QA — User Stories

- As a QA engineer, I want to adjust per-part thresholds so that false rejects drop below target.
- As an operator, I want overlays on fails so that I can quickly route to rework.
- As a line supervisor, I want latency dashboards so that I can detect bottlenecks.
- As a compliance officer, I want audit trails per decision so that we can pass audits.
- As a maintainer, I want model versioning so that rollbacks are safe.
- As a process engineer, I want pose deviations reported so that I can tune fixtures.
- As IT security, I want mTLS and RBAC so that access is controlled.
- As a data steward, I want data retention policies so that storage is predictable.
- As a planner, I want fail taxonomy so that I can prioritize improvements.
- As a quality director, I want trend reports so that I can quantify yield gains.
- As a site lead, I want canary deploys so that risk is minimized.
- As an auditor, I want signed artifacts so that provenance is verified.
