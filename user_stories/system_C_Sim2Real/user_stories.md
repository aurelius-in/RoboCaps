# Sim2Real — User Stories

- As a researcher, I want seeded runs so that results are reproducible.
- As a data curator, I want scenario catalogs so that teams can reuse setups.
- As an ML engineer, I want gap metrics so that I can choose fine-tuning data.
- As an operator, I want dashboards so that I can track progress across runs.
- As a PM, I want reports so that I can communicate improvement milestones.
- As a compliance officer, I want data statements so that usage is documented.
- As DevOps, I want quotas so that GPU usage stays within budget.
- As a lead, I want auto-stop on regressions so that we avoid wasted cycles.
- As a scientist, I want overlay artifacts so that I can inspect errors.
- As an integrator, I want APIs so that I can trigger runs from CI.
- As a site lead, I want alerts on drift so that I can schedule retraining.
